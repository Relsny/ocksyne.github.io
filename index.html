Où héberger ton bot

DCAS ne fournit pas d’hébergement. Tu achètes le code, tu l’installes, tu le lances. Un hébergement gratuit peut s’arrêter, redémarrer ou être repris. C’est suffisant pour commencer, pas une promesse de bot toujours en ligne.

1. Ton ordinateur — 0 €

Le plus simple. Le bot est en ligne tant que le PC est allumé, réveillé, et connecté. Dès qu’il s’éteint, Discord affiche le bot hors ligne.

  1. Installe Node.js 18 ou plus récent.
  2. Ouvre le dossier du bot. Remplis 👉 METS TON TOKEN ICI 👈.txt.
  3. Dans un terminal : npm install, puis npm run deploy, puis npm start.
  4. Sur le portail Discord, active les intents privilégiés demandés par tes modules (souvent Server Members, parfois Message Content).
  5. Invite le bot avec le lien du README.
  6. Pour qu’il reparte à l’ouverture de session : option « Démarrage automatique avec le PC » (5 €, prix proposé).

2. Oracle Cloud Always Free — 0 € de calcul, avec des conditions

Source : oracle.com/cloud/free et la doc Always Free, lues le 17 novembre 2026. Ça peut changer.

  • Jusqu’à deux VM AMD VM.Standard.E2.1.Micro (1 Go de mémoire chacune).
  • Du calcul Arm Ampere A1 : les 1 500 premières heures d’OCPU et 9 000 Go-heures par mois, ce qui équivaut à 2 OCPU et 12 Go pour un compte Always Free.
  • Une carte bancaire sert à vérifier l’identité. Oracle indique qu’une empreinte temporaire n’est pas un débit.
  • Une VM Always Free peut être reprise si elle a l’air inactive pendant 7 jours : CPU au 95e percentile sous 20 %, réseau sous 20 %, et, sur les formes A1, mémoire sous 20 %. Un petit bot calme peut tomber dans ce cas.
  • La page Free Tier dit aussi qu’un compte laissé inactif 30 jours ou plus peut être considéré comme abandonné.
  • « Out of host capacity » arrive : pas de place Always Free dans la région. Il faut réessayer ou changer de domaine de disponibilité.
  1. Crée le compte sur la page Free Tier et choisis une région d’accueil.
  2. Crée une instance Always Free (Ubuntu ou Oracle Linux), avec une clé SSH. Ouvre le port 22 seulement pour ton adresse si tu sais le faire.
  3. Connecte-toi en SSH. Installe Node.js 18+.
  4. Envoie le dossier du bot (scp ou git). Ne mets pas le token dans un dépôt public.
  5. npm install, remplis le fichier du token, npm run deploy, puis npm start.
  6. Pour qu’il reparte tout seul : un service systemd Restart=always, ou pm2 startup. Vérifie avec systemctl status après un redémarrage de la VM.

Ce n’est pas un hébergement « clique et c’est en ligne ». Tu administres un Linux.

3. Ce qui a l’air gratuit, et ne garde pas ce bot allumé

Source : render.com/hosting/discord-bots, lu le 17 novembre 2026.

  • Le service web gratuit de Render s’éteint après 15 minutes sans visite. Il sert à tester une adresse HTTP, pas un bot qui reste connecté à Discord.
  • Render écrit qu’un bot Gateway (celui que tu reçois, en discord.js) se lance sur un worker payant, à partir de 7 $ par mois pour 0,5 CPU et 512 Mo.
  • Heroku n’a plus d’offre gratuite. D’autres plateformes changent souvent : ouvre leur page de prix avant de payer. Les chiffres d’un comparatif ne remplacent pas le site de l’hébergeur.

Pour débuter, le PC suffit. S’il doit rester en ligne la nuit, Oracle Always Free est l’option gratuite la plus sérieuse, avec le risque qu’elle s’arrête. DCAS ne surveille ni l’un ni l’autre.

FAQ

Questions fréquentes

Je dois savoir coder ?

Pas pour t’en servir. Tu suis le guide en français : Node.js, le fichier du token, deux commandes. DCAS ne l’installe pas sur une machine à lui.

Comment je paie ?

50 % d'acompte au début, le reste à la livraison (100 % d'avance pour une commande de moins de 30 €). Paiement par PayPal ou virement. Le moyen exact est confirmé sur Discord.

Le code m'appartient ?

Tu reçois le code pour le faire tourner sur tes serveurs. Il reste crédité DCAS / sir_ocksyne. Le modifier, ou créer d’autres modules à partir de lui, est interdit. Assembler plusieurs modules achetés, y compris avec une IA, est autorisé.

Vous faites des bots musique ?

Non. Les bots qui diffusent de la musique depuis YouTube enfreignent les conditions des plateformes, donc DCAS n'en fait pas.

C'est quoi « le pack vaut le double » ?

La somme des modules du pack est environ le double du prix. Exemple : le Pack Communauté réunit 340 € de modules pour 159 €.

Et si je veux changer quelque chose ?

2 retouches sont incluses. Tu testes le bot sur ton serveur, tu dis ce qui ne va pas, c'est corrigé.

Le bot doit rester allumé ?

Oui. Discord coupe le bot dès que le programme s’arrête. DCAS ne fournit pas cette machine. Tu peux le lancer sur ton PC, ou suivre le guide gratuit d’hébergement.

Je peux tester avant d'acheter ?

Oui : un bot de démo est disponible. Demande l'invitation sur Discord.
