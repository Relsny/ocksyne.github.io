AMOUR — ORGANISATION DES FICHIERS

assets/style.css : apparence générale du site
assets/images/   : photographies, scans, images d'archives
assets/documents/: documents et fichiers associés aux archives

Pour ajouter une image :
1. Dépose-la dans assets/images/
2. Utilise son nom dans une balise image, par exemple :
   <img src="assets/images/nom-de-l-image.jpg" alt="Description">
