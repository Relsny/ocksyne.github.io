# Stats osu!

Profil public et cinq meilleurs scores via l’API officielle osu! v2. Les autres jeux ne sont pas branchés : une API publique s’ajoute dans `lib/osuApi.js` sur le même modèle, sans inventer de chiffres.

## Commandes

- `/osu profil joueur: mode:`
- `/osu scores joueur: mode:`

Modes : osu!, taiko, catch, mania.

## Clés

`OSU_CLIENT_ID` et `OSU_CLIENT_SECRET` dans `👉 METS TON TOKEN ICI 👈.txt`. Crée une application OAuth sur https://osu.ppy.sh/home/account/edit#oauth (client credentials).

## Permissions du bot

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`. Aucun intent privilégié.
