# Anniversaires

Chaque membre enregistre le jour et le mois. Le jour J, le bot poste un message et peut donner un rôle pendant 24 heures.

## Commandes

- `/anniversaire definir jour: mois:`
- `/anniversaire salon` — gérants
- `/anniversaire role` — rôle du jour
- `/anniversaire liste`

## Permissions du bot

Envoyer des messages, Gérer les rôles.

## Intents

`Guilds`, `GuildMembers` (intent privilégié **Server Members**).

Les dates sont dans `data/anniversaires.json`. Le contrôle reprend après un redémarrage.
