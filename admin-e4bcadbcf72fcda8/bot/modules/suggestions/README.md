# Suggestions

`/suggest` publie l’idée avec des votes Pour / Contre. Un gérant du serveur l’accepte ou la refuse, les boutons se figent, et l’auteur reçoit un message privé.

## Commande

`/suggest texte:`

## Permissions du bot

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`. Aucun intent privilégié.

Les suggestions sont dans `data/suggestions.json`.
