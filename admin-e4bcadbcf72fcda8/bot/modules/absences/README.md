# Tableau d’absences staff

Un bouton Absent ouvre une fenêtre : sujet, description, date de retour. Une carte rouge apparaît avec l’avatar, le pseudo, le motif et le compte à rebours Discord. Une copie part dans le salon de logs. Quand la date est passée, une carte verte « De retour » est ajoutée. Le contrôle reprend après un redémarrage.

## Commandes

- `/absence salon`
- `/absence logs`
- `/absence panneau`

Date acceptée : `2026-12-01` ou `2026-12-01 18:00`.

## Permissions

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`.
