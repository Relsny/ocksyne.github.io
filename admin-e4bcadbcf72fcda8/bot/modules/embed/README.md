# Créateur d’embeds

Envoie un message de règlement ou d’annonce (titre, texte, couleur, image, miniature, pied), puis le modifie plus tard avec l’identifiant du message.

## Commandes

- `/embed envoyer` — `titre`, `description`, `couleur`, `image`, `miniature`, `pied`, `salon`
- `/embed modifier message:` — les mêmes champs, sur un message du bot dans ce salon

## Permissions du bot

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`. Aucun intent privilégié.
