# Compteurs de membres

Le nom d’un salon affiche le nombre de membres, d’humains, de bots ou de boosts. Le modèle accepte `{membres}`, `{humains}`, `{bots}` et `{boosts}`.

Discord n’autorise que quelques renommages : le bot attend au moins 6 minutes entre deux mises à jour du même salon. Un salon vocal garde les majuscules ; un salon texte est passé en minuscules par Discord.

## Commandes

- `/compteur ajouter salon: modele:`
- `/compteur retirer salon:`
- `/compteur liste`

## Permissions du bot

Gérer les salons.

## Intents

`Guilds`, `GuildMembers` (intent privilégié **Server Members**, pour distinguer humains et bots).
