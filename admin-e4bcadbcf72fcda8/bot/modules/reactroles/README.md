# Rôles à boutons

Panneau où les membres prennent ou retirent des rôles, en boutons ou en menu déroulant, jusqu’à 25 rôles. Le mode unique retire les autres rôles du même panneau.

## Commandes

- `/roles ajouter role: etiquette:`
- `/roles vider`
- `/roles publier salon: mode: unique: titre:`

## Permissions du bot

Gérer les rôles, Envoyer des messages, Intégrer des liens. Le rôle du bot doit être au-dessus des rôles du panneau.

## Intents

`Guilds` seulement. Aucun intent privilégié.

Les panneaux publiés sont mémorisés dans `data/roles.json`.
