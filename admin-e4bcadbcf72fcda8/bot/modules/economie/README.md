# Économie

Une monnaie propre au serveur : 100 pièces par `/daily` (toutes les 20 h), virements, boutique de rôles ou d’objets, et le solde de chacun.

## Commandes

- `/daily`
- `/balance membre:`
- `/pay membre: montant:`
- `/boutique voir`
- `/boutique ajouter nom: prix: type: role:` — réservé aux gérants
- `/boutique retirer numero:`
- `/acheter numero:`

## Permissions du bot

Envoyer des messages. Gérer les rôles, si la boutique vend des rôles (le rôle du bot doit être au-dessus).

## Intents

`Guilds`. Aucun intent privilégié.

Les soldes sont dans `data/economie.json`.
