# Rappel personnalisé

Remplace l’ancien rappel simple. Chaque rappel a un nom, un texte, une couleur d’embed, une image facultative, et un rythme : chaque jour, chaque semaine, ou un intervalle (`2h`, `1j`).

Si le bot était éteint au moment prévu, le message part une fois au redémarrage. Les occurrences intermédiaires ne sont pas rattrapées en rafale.

Prix catalogue : 5 €.

## Commandes

- `/rappel creer`
- `/rappel liste`
- `/rappel supprimer`

## Permissions

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`.
