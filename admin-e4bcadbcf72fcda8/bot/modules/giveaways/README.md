# Giveaways

Concours avec un bouton Participer, un tirage au sort à la fin, et une relance qui ne reprend pas les gagnants déjà tirés. On peut exiger un rôle, et un niveau si le module Niveaux & XP tourne sur le même bot.

## Commandes

- `/giveaway lancer prix: duree: gagnants: role: niveau:`
- `/giveaway terminer message:` — ID du message du concours
- `/giveaway relancer message:`

## Permissions du bot

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`. Aucun intent privilégié.

Les participations sont dans `data/giveaways.json`. Le tirage reprend après un redémarrage.
