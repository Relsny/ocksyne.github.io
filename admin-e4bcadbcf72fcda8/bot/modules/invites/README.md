# Suivi des invitations

Le bot compare le nombre d’utilisations de chaque invitation avant et après une arrivée, comme InviteLogger. `/invites voir` donne les arrivées, les départs et le net. Un salon de journal reçoit les entrées et les sorties.

Les arrivées pendant que le bot est éteint ne peuvent pas être attribuées après coup. Au redémarrage, l’écart d’utilisations est annoncé comme non attribué, sans inventer d’auteur.

Prix catalogue proposé : 25 €, à confirmer (aucun prix n’était fixé dans le brouillon).

## Commandes

- `/invites voir membre:`
- `/invites salon`

## Permissions

Gérer le serveur (lire les invitations), Envoyer des messages.

## Intents

`Guilds`, `GuildMembers` (privilégié), `GuildInvites`.
