# Message de boost

Quand un membre booste le serveur, le bot envoie un embed de remerciement. L’image et la couleur se règlent avec la commande. Au redémarrage, un boost déjà en cours qui n’a pas encore été annoncé part une seule fois.

Prix catalogue proposé : 10 €, à confirmer (aucun prix n’était fixé dans le brouillon).

## Commandes

- `/boost salon`
- `/boost message` — `{user}` `{server}`
- `/boost couleur`
- `/boost image`

## Permissions

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`, `GuildMembers` (privilégié).
