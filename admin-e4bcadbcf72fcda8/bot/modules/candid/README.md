# Candidatures staff

Un bouton ouvre une fenêtre (jusqu’à 5 questions). Les réponses arrivent dans le salon du staff avec Accepter et Refuser. Le candidat reçoit le résultat en message privé.

## Commandes

- `/candidature salon` — salon du staff
- `/candidature questions` — questions séparées par `|`
- `/candidature panneau`

Les questions par défaut : présentation, motivation, disponibilités.

## Permissions du bot

Envoyer des messages, Intégrer des liens.

## Intents

`Guilds`. Aucun intent privilégié.

Les réponses sont dans `data/candidatures.json`.
